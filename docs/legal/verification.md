# Проверка реализации — 28.09.2026

Проверено локально на изолированных временных базах, внешние провайдеры отключены.

- 5 проверок legalDocuments: блокировка преждевременной публикации, даты, безопасный HTML, хеши и отклонение неподтверждённого/устаревшего согласия, полный снимок и передача ошибки записи.
- 4 интеграционных проверки selfRegistration: создание организации и сессии, отсутствие дубликатов, изоляция организаций, публичные документы и доказательство акцепта с подтверждённым email. Незавершённая заявка без согласия не может завершить регистрацию после включения опубликованных условий.
- 8 проверок локализации: покрытие казахского словаря, параметры, ссылки на ключи и существующие сценарии интерфейса.
- Проверки типов API, web и contracts прошли; сборка web прошла. Сборщик сообщает об имеющихся крупных частях приложения и комментариях зависимости Zod; ошибок сборки нет.
- `git diff --check` — без ошибок.
- `npm run legal:check` намеренно возвращает неготовность: дата вступления, утверждение, размещение, получатели, исполнение сроков и меры ИБ ещё не подтверждены. Подтверждение email владельцем внесено.

В старом тесте регистрации исправлены ожидания по текущему Free: WhatsApp, AI-песочница и поддержка уже доступны по существующему каталогу. Производственный код тарифов не менялся.

Визуальная проверка браузером не выполнена: инструмент завершился при запуске из-за ошибки своей песочницы (`TIOCSTI`). Адаптивные стили добавлены, но корректность мобильного отображения требует проверки в браузере. Не считать серверный тест HTML визуальной проверкой.

Рабочий bsqr.kz, миграция Render → ps.kz, доставка писем, фактические копии, MFA, удаление, подпись приказа и правовая достаточность пакета этим тестированием не подтверждены. Изменения в production не развёрнуты.
