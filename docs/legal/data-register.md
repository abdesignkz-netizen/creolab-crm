# Необходимый и достаточный перечень персональных данных BasQar

Проект приложения к приказу ТОО «CreoLab». Утверждает директор Булан Асхат Болатұлы. Владелец реестра — назначенное ответственное лицо. Дата/редакция утверждения: __________.

Перечень относится к фактически включённым операциям. Ненужное поле не собирать «на будущее». ТОО определяет цели для собственных аккаунтов и расчётов; организация-клиент определяет цели своих CRM-данных, а ТОО обрабатывает их в согласованном объёме. Договор с клиентом сам по себе не даёт согласия за его работников и клиентов.

Закрытые ключи ЭЦП, PIN и CVV не включать в перечень: платформа не должна их собирать. Проверить логи и обращения, чтобы пользовательские вложения не обходили этот запрет. ИИН не использовать как универсальный идентификатор аккаунта без необходимости.
