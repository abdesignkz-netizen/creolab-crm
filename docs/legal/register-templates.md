# Формы внутренних журналов

Проекты форм ТОО «CreoLab». Рабочие записи хранить в защищённом хранилище с именным доступом и утверждённым сроком, не в публичном репозитории. Пустая форма не подтверждает выполненное действие. Владелец всех форм — ответственное лицо, исполнитель указывается в записи.
