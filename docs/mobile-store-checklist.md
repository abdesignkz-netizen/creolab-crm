# BasQar — приёмка и сведения для магазинов

Дата подготовки: 03.11.2026. Этот список содержит оставшиеся действия, а не подтверждение их выполнения. Сборки, запуск на телефоне и публикация — разные этапы.

## Обязательная приёмка на устройствах

Проводить с отдельными тестовыми компаниями. Не отправлять реальные сообщения клиентам и не проводить настоящую оплату ради проверки.

| Сценарий | Ожидаемый результат | Сейчас |
| --- | --- | --- |
| Чистая установка, холодный старт | BasQar, корректная иконка/splash, без белого зависшего экрана | Код/генерация; устройство не проверено |
| Вход, неверный пароль, восстановление | Существующий аккаунт; понятные ошибки; пароль не попадает в bridge | Сервер/JS проверены; устройство не проверено |
| Перезапуск, истечение сессии, отзыв | Действующая cookie сохраняется; отозванная сессия не работает | Серверная регрессия; устройство не проверено |
| Несколько компаний/смена пользователя | Данные не смешиваются; push не открывает чужое уведомление | Серверный тест пройден |
| Основные разделы | Сегодня, диалоги, клиенты, заявки, задачи, сделки, Control, документы, статистика, AI и интеграции | Повторно используется web; полный device-прогон нужен |
| Создать/изменить задачу | Изменение видно в веб-кабинете той же компании | Общее API; сквозной device-прогон нужен |
| Диалоги | Отправка в тестовый канал, обновление истории, длинные тексты, вложения, отсутствие дублей | Требуется тестовый канал/устройство |
| Клавиатура | Поле ввода не закрыто; textarea/нижнее меню доступны; Android Back сначала закрывает клавиатуру | Настройки resize/safe-area; нужна проверка |
| Камера/фото/микрофон | Согласие, отказ, повторное включение из настроек; без лишних разрешений | Generated permissions проверены; устройство не проверено |
| PDF/DOCX/изображение | Просмотр PDF, сохранение/отправка до 20 МБ; понятная ошибка большого файла; очистка cache | Bridge/лимиты проверены; системное меню не проверено |
| Несохранённая форма | Внутренняя навигация/Назад не теряет данные молча | Существующий web-механизм; проверить WebView |
| Нет сети/сервер 5xx | Ошибка и рабочая кнопка повторения; нет ложного выхода/успеха | Код; требуется устройство |
| Google/Instagram OAuth | Системный браузер, успех/отмена/ошибка/истёкший state; возврат в исходную компанию | Сервер и nonce проверены; провайдер/устройство не проверены |
| Телефон/email/внешняя ссылка | Системное приложение, блокировка неизвестных схем | Policy-тест пройден; устройство не проверено |
| Push foreground/background/killed | После согласия, без частных данных, правильная компания при открытии | Очередь и recipient проверены; APNs/FCM не проверены |
| Push logout/переустановка/смена аккаунта | Отзыв/новая регистрация, нет доступа к прежнему пользователю | Сервер проверен; OS-проверка нужна |
| Тихие часы/повтор receipt/ошибка сети | Нет повторной отправки с неизвестным результатом | Серверные тесты пройдены |
| Universal/App Links | Только разрешённые UI-адреса; API callback остаётся серверным | Выключено до реальных domain associations |
| Подписание NCALayer | Понятное требование продолжить на компьютере; нет ложной подписи | Автотест пройден; мобильная ЭЦП не реализована |
| Доступ/тариф | Нет покупки цифровой подписки через внешний эквайринг внутри приложения | Отдельный native-режим; device-аудит нужен |
| Удаление аккаунта | Запрос принят один раз; оператор исполняет его и сообщает результат | Запрос/аудит готовы; процесс исполнения и срок должны быть подтверждены |
| iPad, небольшой iPhone, Android 16 | Портрет/альбом, клавиатура, крупный шрифт, safe area, доступность кнопок | Требуется device-прогон |
| Android 16 KB / release shrinking | Запуск именно итогового release APK из итогового AAB | Требует native-сборки |

## Черновик карточки магазина

**Название:** BasQar

**Подзаголовок / короткое описание:** Клиенты, диалоги и задачи вашей компании в одном рабочем кабинете.

**Описание:**

BasQar помогает команде работать с обращениями клиентов, вести сделки и контролировать задачи. Приложение использует тот же кабинет и данные, что и веб-версия BasQar.

В приложении можно просматривать обращения и историю общения, работать с клиентами и сделками, назначать задачи, использовать BasQar Control, готовить и просматривать документы, следить за показателями и настраивать ИИ-менеджера. Доступные функции зависят от прав сотрудника, настроек компании и подключённых каналов.

Для работы нужен существующий аккаунт BasQar и интернет. Разрешения на уведомления, камеру, микрофон и выбор фото используются только для соответствующих функций. Подписание документов через NCALayer выполняется в веб-кабинете на компьютере.

Это черновик: перед публикацией сверить все заявленные возможности с принятой сборкой. Не добавлять обещания «все функции офлайн», «мобильная ЭЦП», «100% точность ИИ» или «доставка уведомлений гарантирована».

**URL после развёртывания и проверки:** privacy `https://bsqr.kz/legal/privacy`; deletion `https://bsqr.kz/account-deletion`. Support URL и email должен подтвердить оператор сервиса. Сведения о юридическом лице, контактах, торговых марках и территориях распространения берутся из действующих документов владельца, не из предположений разработчика.

## Инвентаризация для privacy-форм

Это техническая заготовка, не заполненная декларация магазина. Оператор должен сверить фактическую обработку и сроки хранения.

| Данные | Для чего используются | Где обрабатываются |
| --- | --- | --- |
| Email, профиль, роль, компания | Вход, права, работа команды | Существующий BasQar backend |
| Контакты клиентов, обращения, сообщения, сделки и задачи | Работа CRM по поручению компании | BasQar и подключённые компанией каналы |
| Фото/документы/голосовые файлы, выбранные пользователем | Вложения, документы, существующие AI-функции | Существующее хранилище и используемые им обработчики |
| Push token, идентификаторы уведомления/компании | Доставка и безопасное открытие уведомлений | BasQar → Expo → APNs/FCM |
| Сессионная cookie | Вход пользователя | Защищённое хранилище WebView и сервер |
| Технические сетевые данные | Доставка запросов, безопасность | Существующая инфраструктура сервера/провайдеров |
| Запрос на удаление аккаунта | Исполнение запроса и аудит | Существующая поддержка BasQar |

Новый мобильный слой не запрашивает адресную книгу/геолокацию, не добавляет рекламные SDK, не сохраняет пароль в SecureStore и не добавляет аналитическую запись экрана. Это не означает, что всё приложение можно объявить «не собирающим данные»: кабинет и существующие AI/интеграции продолжают обрабатывать рабочие данные.

## Заметка для App Review (заполнить после реальной приёмки)

BasQar is a companion business workspace for existing company accounts. It uses the same authorized company data as the web application. The mobile app does not sell BasQar subscriptions or link to an external subscription checkout. Native functionality includes notification handling and system document sharing. Desktop NCALayer signing is not available on mobile. Account deletion can be initiated from the native app menu or the account page.

Provide a dedicated demo email/password through the store's private review form, a populated demo company and exact steps for testing dialogs/tasks/files/notifications. Do not use the owner's real account or include credentials in this repository.

## Решение о выпуске

Не отправлять на модерацию, пока нет реальных подписанных сборок, device-приёмки, заполненных privacy-форм и работающего процесса удаления. Текущие предупреждения зависимостей также должны пройти отдельный разбор перед публикацией. Отдельное разрешение владельца на отправку обязательно.

### Дополнительная проверка выгрузок

На iOS и Android проверить CSV клиентов, CSV/Excel статистики, PDF статистики, АВР, договор и архив с ЭЦП. Для PDF статистики ожидается системное меню сохранения с настоящим PDF, без пустого окна. Оригиналы документов должны сохраняться без изменения. Проверить отмену меню, повторное скачивание, длинный отчёт и превышение лимита. Автоматические проверки передачи пройдены; проверка рендеринга и системного меню на реальных устройствах ещё не выполнена.
