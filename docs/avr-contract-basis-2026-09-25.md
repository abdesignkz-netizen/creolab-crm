# Номер договора в АВР

Исправлено получение основания из связанного договора, реквизитов счёта и проверенных
данных ранее импортированного PDF-счёта. При создании по сделке учитывается последний
неотменённый счёт; явно выбранный договор имеет приоритет. Счёт «Без договора» не
получает случайный договор из сделки. Связи проверяются по tenant и dealId.

Номер внешнего договора сохраняется в снимке АВР без создания фиктивной карточки договора.
Дата берётся из счёта или соответствующего договора; если её нет, дата не выдумывается.
При импорте новых счетов номер сохраняется также в Invoice.contractNumber.

Пустое основание старых DRAFT/VALIDATED восстанавливается при чтении и экспорте без
изменения подписанных версий. При сохранении сохраняются снимок и связи; перед локальным
подписанием исправленный снимок фиксируется вместе с PDF. Проверка АВР сохраняет основание.

Проверены тесты avrWorkflow, avrExcel, avrReadiness, avrSigning, manualPdfImport:
57 сценариев (включая повторную проверку после исправления тестового освобождения PDF).
Проверка типов прошла. PDF и Excel проверены на наличие номера из счёта. Случаи чужого
tenant/сделки, явно выбранного договора, отсутствующей даты и замороженных версий покрыты.
