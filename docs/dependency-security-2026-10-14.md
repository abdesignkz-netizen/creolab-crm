## Изменения

- **Prisma:** ограниченный override `@prisma/config → deepmerge-ts 8.0.2`. Prisma остаётся на 6.19.3. Проверены генерация клиента и загрузка JS-конфига с вложенными настройками миграций через реальный загрузчик Prisma. Изменения совместимости восьмой версии описаны в [релизе deepmerge-ts](https://github.com/RebeccaStevens/deepmerge-ts/releases/tag/v8.0.0).
- **ExcelJS и Xcode:** ограниченные overrides `uuid 11.1.1`. Проверены именно используемые CommonJS-вызовы: идентификатор условного форматирования Excel и идентификатор объекта Xcode. Проверен цикл записи/чтения XLSX. API версии выбран с учётом [релиза uuid 11.1.1](https://github.com/uuidjs/uuid/releases/tag/v11.1.1).
- **Сертификаты и CMS:** рабочие импорты `node-forge` заменены на ASN1js 3.0.10 и существующий `node:crypto.X509Certificate`. Разбор ограничен 8 MiB, глубиной 64 и 10 000 ASN.1-узлами; лишние байты отклоняются. Выбор сертификата сохраняет сопоставление issuer/serial и SubjectKeyIdentifier, неоднозначный подписант не принимается. Криптографическую проверку и доверие к цепочке по-прежнему определяет Kalkan, а не парсер метаданных.
- **Тестовые сертификаты:** forge нужен только для синтетических тестовых данных. Зависимость перенесена в корневые `devDependencies`, поскольку общий тестовый запуск выполняет `scripts/test-api.mjs`. Это важно для сборки: если оставить её в API devDependencies, общий lock-файл с мобильным Expo способен оставить forge даже после `npm prune --omit=dev`. Проверено, что после переноса в чистой серверной установке физически отсутствуют node-forge, Expo и React Native. Предупреждение forge не скрыто: он по-прежнему попадает в аудит общего мобильного дерева. [Описание уязвимости forge](https://github.com/advisories/GHSA-86w9-cpqp-85rv).
- **Dockerfile API:** выбор рабочих пакетов дополнен явным `--include-workspace-root=false`, чтобы инструменты общего тестового запуска не попадали в образ. Установка, генерация Prisma, веб-сборка и удаление dev-пакетов воспроизведены вне Docker на macOS.

## Что осталось

В мобильном дереве остаются пять исходных проблем и их зависимые пакеты:

| Пакет | Причина, по которой не выполнен принудительный override |
| --- | --- |
| braces | В проверенном текущем дереве отсутствует исправленная совместимая версия; npm предлагает смену основной версии React Native. |
| sprintf-js | Аналогично: замена затрагивает React Native/Jest и инструменты сборки. |
| decode-uri-component | Исправленная 0.5.0 имеет ESM API, а установленный query-string использует CommonJS-вызов. Пробный override отменён. Обновление React Navigation отдельно от Expo Router также выявило несовместимость. |
| image-size | Исправленная ветка 2.x меняет API, которое вызывает установленный Metro. Нужна совместимая версия Metro/Expo. [Изменения API image-size 2](https://github.com/image-size/image-size/releases/tag/v2.0.0). |
| node-forge | Остаётся в инструментах Expo; исправленной версии npm audit не предлагает. В API/сайте пакет отсутствует. |

Следующий этап для оставшихся 29 записей — согласованное обновление мобильного Expo/React Native/Metro с проверкой deep links, SecureStore, навигации и нативных сборок, а для пакетов без исправления — замена зависимого инструмента либо проверенное исправление upstream. `npm audit fix --force` не применялся. Деплой, реальные сообщения и платежи не выполнялись.
