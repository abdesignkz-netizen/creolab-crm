# Рабочее подключение CreoLab к ИС ЭСФ на Render

Сообщение «Подключение к ИС ЭСФ выключено на сервере» означает, что
сервер вернул `system.esfEnv=off`. Без `ESF_ENV` код также выбирает `off`.
Изменение интерфейса и повторная подпись не включают серверное подключение.

Для сервиса `creolab-crm` в Render → Environment нужны следующие значения:

```dotenv
ESF_PROVIDER=live
ESF_ENV=prod
ESF_ALLOW_PROD=1
ESF_ALLOW_LIVE_SEND=1
ESF_BASE_URL=https://esf.gov.kz:8443/esf-web
```

Они также заданы в `render.yaml` для сервиса под управлением Blueprint.
Если сервис настроен вручную, публикация `render.yaml` не заменяет изменение
его Environment. Нужно сохранить значения через **Save and deploy** либо
**Save, rebuild, and deploy** и дождаться успешного запуска сервиса.
Не менять прочие переменные сервиса.

После запуска проверить в CRM → Интеграции → ИС ЭСФ, что сервер показывает
`provider=live`, `esfEnv=prod`, `endpointHost=esf.gov.kz`, `liveSendAllowed=true`.
В организации должна быть включена интеграция ИС ЭСФ и заполнены реквизиты.
Затем пользователь проходит авторизацию и подписывает документ через свой
NCALayer. Переключение окружения само по себе документы не отправляет.

Успех настройки сервера не равен успешной регистрации АВР/ЭСФ: завершение
проверяется по ответу портала, внешнему идентификатору, номеру регистрации
и статусу документа. Ошибки авторизации, сертификата, реквизитов или ответа
портала нужно проверять отдельно, если они появятся после включения.

Документация Render: https://render.com/docs/configure-environment-variables
